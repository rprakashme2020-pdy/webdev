# PEE AAR DIGITAL

Official portfolio and marketing website for Prakash Ravikumar, built with HTML, CSS, and JavaScript.

## Features
- Black-and-white responsive editorial design, including founder portrait
- Interactive four-step customer journey with a decision point
- Studio Andy, Live Rain, TN Today, One Tap and Prakash Portfolio projects
- Single primary CTA: **Review Your Website for Free** (WhatsApp enquiry)
- No database or paid API required

## Local preview
Open `index.html` directly in a modern browser.

## Notes
Portfolio previews are generated by the third-party public WordPress mShots image service; they may take time to load and have no uptime guarantee. No real customer metrics are claimed. For permanent previews, replace those URLs with screenshots stored locally.
