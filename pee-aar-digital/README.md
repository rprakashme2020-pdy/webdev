# PEE AAR DIGITAL — Prakash Digital Marketing

This is the **complete replacement** of the previous PEE AAR DIGITAL portfolio, using the user's uploaded `index (1).html` as `index.html` without redesigning or merging sections.

## Website

- Single static `index.html` with inline CSS and JavaScript
- Full-screen Three.js/WebGL city map: Pondicherry, Chennai and Bengaluru
- About, services, project process, and contact sections
- Embedded founder portrait
- WhatsApp contact button and click-to-call
- Free hosting compatible (no build step, database, or paid API)

The site loads Google Fonts and Three.js r128 from external CDNs, so the 3D map needs an internet connection and a browser supporting WebGL.
